# UI mockups

One clickable HTML prototype of the whole app: the reference iOS and Android are built against. Open [`app/index.html`](app/index.html) in a browser, or on a phone via [htmlpreview](https://htmlpreview.github.io/?https://github.com/YoAgain/yo/blob/main/design/mockups/app/index.html).

It covers sign-up (name field: spinner, hints, taken, reserved, offline; attested 4 or 12 characters), sign-in by linking (§2.5) or recovery key and passkey (§2.4), the friend list (bots `/NAME`, groups `#NAME`, Yo counts, requests from strangers, add friend), settings, account backup and Devices (remove, 16-device limit). The Simulate panel switches device check, network delay, offline, number of devices and a second phone frame for linking.
